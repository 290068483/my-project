# 消息提示系统优化文档

## 🎯 优化目标

解决原有系统中同一时间可能出现多个消息提示重叠的问题，实现类似 RuoYi 框架的单例模式消息提示系统。

## 🔧 技术实现

### 核心原理

1. **单例模式**: 确保同一时间只能显示一个消息提示
2. **消息队列**: 多个消息会自动排队等待显示
3. **优先级处理**: 错误消息具有最高优先级，会立即显示
4. **自动管理**: 消息关闭后自动处理队列中的下一个消息

### 关键特性

- ✅ **防止消息叠加**: 同一时间只显示一个消息
- ✅ **智能队列管理**: 自动排队，最多保存5个消息
- ✅ **错误消息优先**: 错误消息会打断当前消息立即显示
- ✅ **自动清理**: 消息关闭后自动处理下一个
- ✅ **兼容原有API**: 无需修改现有代码

## 📚 API 文档

### 基本消息方法

```typescript
// 普通消息（会排队）
MessageUtils.success("操作成功！");
MessageUtils.warning("请注意！");
MessageUtils.info("信息提示");
MessageUtils.error("操作失败！"); // 错误消息会立即显示

// 立即消息（打断当前消息）

MessageUtils.warning("立即警告", 3000, true);
MessageUtils.info("立即信息", 3000, true);
MessageUtils.error("立即错误", 3000, true);
```

### 通知方法

```typescript
// 通知提示（右上角，支持单例模式）

```

## 🔍 核心实现

### 单例管理

```typescript
class MessageUtils {
  private static currentMessageInstance: MessageInstance | null = null;
  private static messageQueue: MessageQueueItem[] = [];
  private static isShowingMessage = false;

  private static showMessageInternal(message, type, duration) {
    // 关闭当前消息
    this.closeCurrentMessage();

    // 显示新消息
    this.currentMessageInstance = ElMessage({
      message,
      type,
      duration,
      onClose: () => {
        this.currentMessageInstance = null;
        this.isShowingMessage = false;
        // 处理队列中的下一个消息
        setTimeout(() => this.processMessageQueue(), 100);
      },
    });
  }
}
```

### 队列管理

```typescript
private static processMessageQueue() {
  if (this.isShowingMessage || this.messageQueue.length === 0) return

  const nextMessage = this.messageQueue.shift()
  if (nextMessage) {
    this.showMessageInternal(
      nextMessage.message,
      nextMessage.type,
      nextMessage.duration
    )
  }
}
```

## 🎯 最佳实践

1. **错误消息**: 使用 `immediate: true` 确保立即显示
2. **成功消息**: 使用较短的显示时间（2-3秒）
3. **队列控制**: 避免在短时间内发送大量消息
4. **用户操作**: 重要操作前清空消息队列
5. **调试模式**: 使用统计功能监控消息使用情况

## 📈 性能优化

- 队列最大长度限制为5，防止内存泄漏
- 自动清理过期的消息实例
- 100ms延迟处理队列，避免频繁操作
- 支持手动清空队列和关闭所有消息
