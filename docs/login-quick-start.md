# RuoYi-Vue 登录功能快速使用指南

## 🚀 快速开始

### 1. 启用增强登录组件

将默认登录路由指向新的增强登录组件：

```typescript
// src/router/index.ts
{
  path: "/login",
  name: "Login",
  component: () => import("@/views/user/LoginViewEnhanced.vue"),
  meta: {
    requiresAuth: false,
    title: "登录",
    hidden: true,
  },
}
```

### 2. 体验多种登录方式

增强登录组件支持以下登录方式：

#### 📱 账号密码登录

- 输入用户名和密码
- 支持图形验证码
- 支持记住密码功能

#### 📱 手机号登录

- 输入手机号
- 获取短信验证码
- 验证码登录

#### 📱 扫码登录

- 使用微信等应用扫码
- 快速安全登录

### 3. 测试登录功能

在浏览器控制台中运行测试：

```javascript
// 打开浏览器控制台，运行测试
testRuoYiLogin();
```

## 🔧 配置说明

### API接口配置

登录相关API接口已按RuoYi-Vue标准优化：

```typescript
// 主要接口
/login          - 用户登录
/captchaImage   - 获取验证码
/getInfo        - 获取用户信息
/getRouters     - 获取用户路由
/logout         - 用户退出
```

### 权限控制

路由守卫已集成RuoYi标准权限控制：

```typescript
// 路由meta配置示例
meta: {
  requiresAuth: false,           // 需要登录
  permissions: ['user:view'],   // 需要权限
  roles: ['admin', 'user'],     // 需要角色
  title: "页面标题"
}
```

### 验证码配置

支持多种验证码类型：

```typescript
// 验证码API
getCaptchaImage(); // 图形验证码
sendSmsCode(); // 短信验证码
sendEmailCode(); // 邮箱验证码
```

## 🔍 故障排查

### 常见问题

1. **验证码无法显示**
   - 检查后端验证码接口是否正常
   - 确认网络连接状态
   - 查看浏览器控制台错误信息

2. **登录失败**
   - 确认用户名密码正确
   - 检查验证码是否输入正确
   - 查看后端接口返回信息

3. **权限问题**
   - 确认用户角色权限配置
   - 检查路由meta配置
   - 查看用户Store中的权限信息
